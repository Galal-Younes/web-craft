# Web Craft

A responsive business landing page built with **HTML** and **CSS**, created as a front-end practice project. Like `kasper` and `Leon`, it follows the same core exercise — building out a business landing page layout (features, services, business details) — used to repeatedly train HTML/CSS fundamentals.

## What This Project Practices

- Structuring a landing page with multiple content sections (features, services, about)
- Clean, organized HTML markup
- CSS styling and layout consistency

## Tech Stack

- **HTML5** — page structure
- **CSS3** — styling and layout

## Getting Started

Open `index.html` directly in any modern browser — no build tools or dependencies required.

## Why This Project

Part of a set of landing-page practice builds (`kasper`, `Leon`, `web-craft`) done to repeat the same fundamental exercise multiple times and build fluency with HTML/CSS layout patterns.
